## ⚙️ Local Development Setup

### Prerequisites
* **Node.js**: v18.18+ or v20+ recommended
* **npm**: v9+

### 1. Clone the repository
```bash
git clone https://github.com/takwahafyen/takwahafyen-portfolio.git
cd takwahafyen-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Environment Variables (Optional)
Create a `.env.local` file in the root directory (defaults are already configured):
```env
NEXT_PUBLIC_EMAILJS_SERVICE_ID=service_cgt3f6o
NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=template_qnvqb1k
NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=w9ZBf1nKfArcRxsNB
```

### 4. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 5. Build for production
```bash
npm run build
npm run start
```
